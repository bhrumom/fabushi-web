连接器隐私说明

更新日期：2026 年 10 月 9 日。本说明补充官网的一般隐私说明，适用于 Fabushi 的 Google 与 GitHub MCP 连接器。

Google 与 GitHub 连接

Fabushi 登录与服务授权相互独立。只有你安装并连接某项服务后，Fabushi 才会按该连接器所需的权限访问相应数据。Google 连接器可能访问邮件与草稿、文件、文档、表格、演示文稿、日历、Chat 消息或联系人；GitHub 连接器可能访问仓库和账号信息。具体权限以该服务的授权页面为准。

数据用途与分享

连接器数据用于执行你发起的工具请求、展示结果及完成相关任务。工具请求会发送给对应的 Google 或 GitHub 服务；当你在 AI 对话中使用工具时，相关请求与结果可能发送给当前配置的模型服务及 Fabushi 的任务处理服务。请只授予完成任务所需的权限。Fabushi 不出售 Google 用户数据，不将其用于广告，也不将其用于训练通用 AI 或机器学习模型。Fabushi 对从 Google API 收到的信息的使用和向其他应用的传输遵守 Google API Services User Data Policy，包括 Limited Use 要求。

凭据、保存与删除

桌面端使用原生加密存储保存已连接服务的凭据；系统安全存储不可用时，凭据仅在当前会话中保留。授权服务处理短期授权尝试和加密的凭据交付，并保留账号连接元数据。授权完成、消费、取消或过期后会清除交付内容；已取得的工具结果可能保留在相关对话或任务记录中，按照该记录的保存与删除机制处理。

断开与撤销

你可以在 Fabushi 插件设置中断开或卸载连接器，移除本机凭据并请求撤销服务授权。如果服务撤销失败，界面会提示；你也可以在 Google 账号的第三方连接或 GitHub 的应用授权设置中直接撤销。删除连接器不会自动删除已保存的对话、提供方账号中的原始数据或已完成的写入。其他数据查询、更正或删除请求请联系 support@ombhrum.com。
